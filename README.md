# Log Analyzer Script

## Description
A simple bash script that scans log files to detect:
- passwords
- failed login attempts

## Features
- Detects sensitive data in logs
- Counts occurrences
- Generates output report

## How to Run
chmod +x scripts/scan.sh
./scripts/scan.sh

## Output
- Displays results in terminal
- Can be saved to output/result.txt
